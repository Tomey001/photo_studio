## 📸 LensCraft Studio Appointment Scheduling System

LensCraft Studio Appointment Scheduling System is a full-featured web-based booking and studio management application developed for photography studios. The system streamlines appointment scheduling, improves customer communication, and provides administrators with tools to efficiently manage bookings and monitor business performance.

Built using **Python (Flask)**, **SQLite**, **Jinja2**, **HTML**, **Bootstrap 5**, **JavaScript**, and **Chart.js**, the application offers a modern, responsive interface for both customers and administrators.

### ✨ Features

- 📅 Online appointment booking without requiring customer accounts
- ⏰ Real-time slot availability with already-booked time slots automatically disabled
- 🚫 Server-side double-booking prevention
- 🔐 Secure administrator authentication with password hashing and session management
- 📊 Interactive analytics dashboard showing:
  - Total bookings
  - Pending, approved, rejected, and completed bookings
  - Approval rate
  - Busiest time slot
  - Bookings per month
  - Most popular services
  - Booking status breakdown
- 📧 Automated email notifications using Flask-Mail:
  - Booking confirmation
  - Approval notification
  - Rejection notification
  - 24-hour appointment reminders
  - Review request emails
- 💬 WhatsApp notifications powered by Twilio
- 🤖 AI Photography Assistant that generates personalized:
  - Pose recommendations
  - Outfit ideas
  - Background suggestions
  - Lighting styles
  - Prop recommendations
  - Photography tips
- ⭐ Customer review and 5-star rating system with secure one-time review links
- 🖼️ Responsive service gallery showcasing previous photography work
- ⏰ Automated reminder scheduling using APScheduler
- 📱 Responsive design optimized for desktop, tablet, and mobile devices

### 🎯 Project Objectives

The project was developed to digitize photography studio appointment management by reducing manual scheduling, preventing booking conflicts, improving customer communication, and enhancing the overall booking experience through automation and AI-powered photography recommendations.
