Developed a full-featured web-based booking and studio-management system for a photography studio using Python (Flask), SQLite, Jinja2, HTML, Bootstrap, and Chart.js. Customers book appointments through a clean, validated interface with real-time slot availability that greys out already-booked times, while a secure admin dashboard lets staff approve, reject, and complete bookings and view business analytics (bookings per month, popular services, approval rate) through interactive charts. The system sends automated notifications by email (Flask-Mail) and WhatsApp (Twilio) — including booking confirmations, approvals, and 24-hour appointment reminders driven by a background scheduler (APScheduler) — and features a customer review-and-rating system and a responsive service gallery. Built with server-side double-booking protection and secure, session-based authentication.
